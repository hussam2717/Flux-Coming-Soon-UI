# Flux-Coming-Soon-UI
A modern and responsive Coming Soon / Launch Landing Page built using HTML, CSS, and JavaScript. Perfect for startups, product launches, or personal projects.

Live Demo - 

✨ Features
🔥 Clean and modern UI design
⏳ Countdown timer (Days / Hours / Minutes / Seconds)
📩 Email subscription input field
🌙 Dark gradient background with glowing effects
📱 Fully responsive layout
⚡ Lightweight and fast

🛠️ Tech Stack
HTML5
CSS3 (Flexbox + Gradients)
JavaScript
